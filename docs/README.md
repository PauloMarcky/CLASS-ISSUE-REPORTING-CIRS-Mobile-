# Project Documentation

This directory separates design, assessment, test, and evidence documents from application source code.

## Structure

- `week13_sa7.md` - Week 13 workflow and automation decision record.
- `week13/` - Week 13 Word artifacts submitted for SA7.
- `week15_ia6/` - Week 15 test strategy, traceability, diagrams, defects, fixes, and report.
- `week15_ia6/evidence/` - Test output, screenshots, API evidence, dependency checks, and controlled data.
- `week15_ia6/Week15_IA6_Evidence_Pack.docx` - Consolidated Word evidence portfolio.

## Source Areas

- `lib/` - Flutter Web and Android application.
- `backend/` - Node.js/Express API.
- `backend/sql/` - MySQL schema and automation setup.
- `test/` - Flutter widget/API client tests.
- `scripts/` - Evidence and project helper scripts.

## Evidence Rules

- Keep passwords, JWTs, database credentials, and real personal data out of evidence files.
- Preserve observed failures and recovery evidence.
- Link screenshots and JSON output to the traceability matrix or report.
- Add new evidence without rewriting or deleting earlier baseline evidence.
